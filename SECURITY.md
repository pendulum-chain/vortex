# Security policy

Please report suspected vulnerabilities privately by email to marcel@satoshipay.io. Do not
open a public issue or pull request for them.

Include the affected component, the steps to reproduce, and the impact you expect. We will
acknowledge your report and keep you informed while we investigate and fix it.

The security expectations for each part of Vortex are documented in
[`docs/security-spec/`](docs/security-spec/README.md).
